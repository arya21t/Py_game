# Py_game
🐍 Snake Bite Game

Snake Bite Game is a classic arcade-style snake game created using Python and Pygame. The player controls a snake, eats food to grow longer, and tries to survive as long as possible without hitting the walls or colliding with itself.

⸻

🎮 Game Preview

🟦 Game Start Screen

The snake begins at the center of the screen, ready to move in any direction.

⸻

🍏 Snake Eating Food

Food appears randomly on the screen. Each time the snake eats food, it grows longer and the score increases.

⸻

📈 Score Display

The current score is displayed in real time at the top of the screen.

⸻

💥 Collision & Game Over

The game ends when the snake hits the wall or collides with its own body.

⸻

🔁 Replay Option

After losing, the player can replay the game or quit.

⸻

🕹️ Controls
	•	Arrow Keys – Control snake movement
	•	Left Arrow – Move Left
	•	Right Arrow – Move Right
	•	Up Arrow – Move Up
	•	Down Arrow – Move Down
	•	After Game Over:
	•	Press C to Play Again
	•	Press Q to Quit

⸻

⭐ Features
	•	Classic snake gameplay
	•	Smooth keyboard controls
	•	Random food generation
	•	Real-time score display
	•	Game-over screen with replay option
	•	Simple and beginner-friendly design

⸻

🎯 Objective

The objective of the game is to score as high as possible by eating food while avoiding walls and self-collision. As the snake grows longer, the game becomes more challenging.

⸻

📌 Project Purpose

This project was created to practice and understand:
	•	Game loops
	•	Keyboard event handling
	•	Collision detection
	•	Basic game mechanics

It is ideal for beginners learning game development with Python.
